専門技術コース_基礎知識学習フェーズ  
アプリケーションを作成しよう2の学習課題  
テーマ：ユーザ機能を持ち、読んだ本の感想を投稿するサイト  

前提条件
基本的に、以下の項目について、上記の完成アプリケーションと同じにしてください。  
ページごとのURL  
ページに存在する各種リンク  
処理成功後のリダイレクト先  
処理失敗時にエラーメッセージを表示する画面  
アイコンやリンクのテキスト、ボタンのテキスト有無など（異なる場合には、テストが通らないことがあります）  
Scaffoldは利用しないでください。  
ログイン機能には、meshiterroでも用いた「devise」を使用してください。  
デザインは、「Bootstrap」を使用し、「yarnを用いた方法」で導入してください。  

[STEP1] ユーザログイン前  
ルートパスを設定してください。  
ユーザ名・メール・パスワードで、ユーザの新規登録ができるようにしてください。  
ログイン前／ログイン済みの状態によって、ヘッダーの内容が変わるようにしてください。  
ログインしていない場合は、ヘッダーに以下のリンクが表示されるようにしてください。  
Home ／ About ／ Sign up ／ Log in （大文字／小文字、半角スペースの有無に注意してください。）  
ログイン済みの場合は、以下のリンクがヘッダーに表示されるようにしてください。  
Home ／ Users ／ Books ／ Log out （大文字／小文字、半角スペースの有無に注意してください。）  
ユーザに関するモデル名は、Userとしてください。  
Userモデルのカラム名は、以下のように設定してください。  
name：名前  
introduction：自己紹介文  
ユーザ名とパスワードで、ログインできるようにしてください。  
【ヒント】  
「rails devise ユーザ名 ログイン」、「rails devise 名前ログイン」などで調べてみましょう。  
なお、記事情報が古い場合、記述方法が今とは異なる場合があります。できるだけ新しい記事を探しましょう。  

[STEP2] ユーザログイン後  
投稿データのモデル名は、Bookとしてください。  
Bookモデルのカラム名は、以下のように設定してください。  
title：本のタイトル  
body：感想  
この他にカラムはもう一つ必要ですがご自身で考えてみましょう。  
【ヒント】  
BookモデルはUserモデルと1対Nの関係性にあるということ。  

ユーザ機能関連、投稿機能関連のルーティングは、resourcesを使ってください。  
自分のプロフィールは、以下の内容を追加登録や編集できるように設定してください。  
名前  
画像（写真を登録できるようにしてください。登録していない場合は、任意のNoImageを表示させてください。）  
自己紹介文  

[STEP3] 仕上げ  
ユーザがログインしていない場合、ユーザ機能関連、投稿機能関連の画面にアクセスしても、ログイン画面だけが表示されるように設定してください。  
【ヒント】  
deviseのauthenticate_user!を調べてみましょう。  
Userモデルのカラムのバリデーションは以下の通りにし、有効でない場合はバリデーションエラーを返してください。  
name：一意性を持たせ、かつ2～20文字の範囲で設定してください。  
introduction：最大50文字までに設定してください。  
Bookモデルのカラムのバリデーションは以下の通りにし、有効でない場合はバリデーションエラーを返してください。  
title：空でないように設定してください。  
body：空でない、かつ最大200文字までに設定してください。  
以下の処理の成功時にサクセスメッセージを表示させてください。サクセスメッセージには、「successfully」の言葉が含まれるようにしてください。  
ユーザ新規登録  
ユーザログイン  
ユーザログアウト  
ユーザのプロフィール情報更新  
投稿データの新規投稿  
投稿データの更新  
以下の処理の失敗時にエラーメッセージを表示させてください。エラーメッセージには、「error」の言葉が含まれるようにしてください。  
ユーザ新規登録  
ユーザのプロフィール情報更新  
投稿データの新規投稿  
投稿データの更新  
URLを入力しても、他のユーザが投稿した投稿の編集画面、および他のユーザの編集画面には遷移できないように設定してください。  
投稿データは、投稿者のみ編集や削除ができるように設定してください。  
Bootstrapを使って、以下のものを適用してください。  
ヘッダーのデザイン  
テーブルのデザイン  
グリッドシステム
